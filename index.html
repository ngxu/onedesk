Beta 1.0

For people presenting their own slides.

  • 手机当翻页器，看到当前页、下一页、备注和计时
    Phone as the clicker, with current and next slide, notes and timers
  • 黑屏/白屏、投影上的真实画面、开场前检查
    Black/white, the real projector picture, a pre-event check

    Open the file, scan the code, go

Windows

  • Windows 10 / 11 · PowerPoint 2016 or Microsoft 365 · Spotify app (Standard and Extra, optional)
  • 如出现“Windows 已保护你的电脑”：点“更多信息 → 仍要运行”（安装程序没有付费的代码签名）。
    "Windows protected your PC": More info → Run anyway (the installer is not code-signed).
  • 双击后没反应或提示无法访问：防毒软件在检查新文件，等几分钟再双击。
    Nothing happens, or "can't access": antivirus is still checking the new file; try again in a few minutes.
  • 已经装了旧版 OneDesk：装 Standard 就会直接升级，设置会保留。
    Older OneDesk installed: Standard installs over it; settings are kept.
  • 三个版本可以都装，资料共用（设置、PIN、Cue），同一时间开一个。
    All three can be installed; they share settings, PIN and cues; one runs at a time.

Mac

测试版 · Test version
  • 功能和 Windows 版基本相同，但还没有和真正的 PowerPoint 一起测试过，正式使用前请先试一次。
    Nearly the same features as on Windows, but not yet tested with PowerPoint on a real Mac: try it before an event.
  • 第一次打开：在“应用程序”里按住 Control 点它 → 打开（没有 Apple 签名）。如提示“已损坏”，在“终端”执行 xattr -cr "/Applications/OneDesk Standard.app"（换成你装的版本）。
    First start: Control-click the app → Open (no Apple signature). If it says "damaged", run the line above in Terminal, with your edition's name.
  • 投影画面实时截取需要 macOS 14（Sonoma）以上，第一次用时要允许“屏幕录制”。
    The live projector view needs macOS 14 (Sonoma) or later and the Screen Recording permission.
  • 和 Windows 不同：投影模式只有同步和延伸（只用投影机时合上盖子）；没有 OneDesk Wi-Fi，改用手机热点；不需要“加速”。
    Different from Windows: Duplicate and Extend only (close the lid for the projector only); no OneDesk Wi-Fi, use the phone's hotspot; no speed-up needed.

Phone · tablet

不用下载 · No download

手机和平板是遥控器，用网页打开，不用安装。
Phones and tablets are the remote, in the browser; nothing to install.

  1. 在电脑的 OneDesk 点 Remote，用手机相机扫二维码。
    On the computer, click Remote in OneDesk and scan the code with the phone's camera.
  2. 再选“加到主屏幕”，以后像 App 一样从图标打开。
    Then "Add to Home Screen": it opens like an app from then on.

没有 Wi-Fi 时：OneDesk 可以开自己的 Wi-Fi（Windows），或用手机热点（Mac），或用蓝牙（Android）。
No Wi-Fi: OneDesk's own Wi-Fi (Windows), the phone's hotspot (Mac), or Bluetooth (Android).
